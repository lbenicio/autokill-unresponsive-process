# Contributing to autokill-unresponsive-process

First off, thank you for considering contributing to autokill-unresponsive-process. It's people like you that make open source great.

## How Can I Contribute?

### Reporting Bugs

- **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/your_username/autokill-unresponsive-process/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/your_username/autokill-unresponsive-process/issues/new). Be sure to include a **title and clear description**, as much relevant information as possible, and a **code sample** or an **executable test case** demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Open a new issue to discuss your enhancement. Please provide a clear description of the enhancement and its potential benefits.
- We welcome suggestions that improve performance, usability, and functionality.

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. Make your changes and ensure your code lints.
3. Add tests for your changes.
4. Issue that pull request!

## Styleguides

### Git Commit Messages

- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.
- Reference issues and pull requests liberally after the first line.

### Code Style

- We use [go fmt](https://golang.org/cmd/gofmt/) for code formatting. Please run `make fmt` before committing your changes.
- We use [golangci-lint](https://golangci-lint.run/) for linting. Please run `make lint` and fix any issues before committing your changes.
- Follow the existing coding style. When in doubt, make your code look like the surrounding code.

## Code of Conduct

This project and everyone participating in it is governed by the [autokill-unresponsive-process Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior.
